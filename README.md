# Fuzzy Image Enhancement

A web-based image enhancement project that uses **Fuzzy Logic** to improve the quality and clarity of images.

## 🌐 Live Demo

👉 **[View Live Demo](https://drpavi532002.github.io/fuzzy_image_enhancement/)**

## 📌 About the Project

This project enhances images using a **Fuzzy Logic-based image enhancement technique**.

The input image is processed by analyzing the local pixel values and their relationships with neighboring regions. Fuzzy membership values are used to determine how strongly each pixel belongs to different fuzzy windows.

The enhanced result is then displayed as an output image.

## ⚙️ Main Features

* 🖼️ Upload an image
* 🔍 Fuzzy-based image enhancement
* 📊 Local pixel analysis
* ✨ Improves image clarity and contrast
* 🎨 Supports image enhancement for different image types
* 🌐 Simple and interactive web interface

## 🔄 Working Flow

```text
Input Image
     ↓
Pixel Value Normalization
     ↓
Fuzzy Window Formation
     ↓
Membership Calculation
     ↓
Local Mean & Variance Calculation
     ↓
Pixel Enhancement
     ↓
Enhanced Image
```
