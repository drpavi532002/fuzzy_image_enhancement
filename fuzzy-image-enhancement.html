Algorithm Controls

9 px
Size of the base local fuzzy window (odd, in pixels). Larger = smoother local statistics, smaller = finer local detail.
0.45
Spread of the Gaussian membership function. Lower γ = only near-mean pixels get low membership (sharper fuzziness); higher γ = membership stays high across a wider range.
1.20
Overall gain applied to the combined fuzzy-weighted contribution before it's added back to the pixel.
3 scales
Number of overlapping window scales combined per pixel (1× / 1.6× / 2.2× the base window size).

Concept

How It Works

Eight stages take an image from raw pixel intensities to a fuzzy-enhanced result.

Reference

Algorithm Mathematics

The core operations behind the enhancement, explained in plain language — no unexplained symbols.

1 · Normalization

x_norm = 2 × (x / 255) − 1

x is the original pixel value (0–255). This rescales every pixel into [-1, +1] so the statistics below aren't biased by the absolute brightness of the image.

2 · Local Mean & Std. Deviation

μ = mean(window) σ = std(window)

For the window centred on a pixel, μ is the average normalized intensity and σ is how spread out those values are — computed independently per window.

3 · Local Difference

diff = x_norm − μ

How far this pixel sits from what's "typical" for its neighbourhood.

4 · Normalized Difference

norm_diff = diff / (σ + ε)

Dividing by σ expresses the difference in units of local variability (a tiny ε avoids dividing by zero in flat regions).

5 · Fuzzy Membership

μ(x) = exp( −norm_diff² / (2γ²) )

A Gaussian membership function: pixels close to their local mean get low membership; unusual pixels (edges, texture) get high membership — γ is the strength slider.

6 · Weighted Contribution & Reconstruction

contribution = μ(x) × norm_diff × strength x_enhanced = clip(x_norm + Σ contribution, −1, 1) x_out = round( (x_enhanced + 1) / 2 × 255 )

Contributions from every overlapping window are summed, added back to the pixel, then converted back to the 0–255 range for display.
